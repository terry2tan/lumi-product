# 侧栏素材

- 文件、新对话、下拉、更多、添加、置顶、删除、勾、项目展开与收起、自动任务、Lumi 形象：复制自八月版 `260818 项目与文件`。
- 行情、商城、个人中心：复用当前 Demo 的工作台、商城与头像图标。
- 首页：用户提供的 [Lucide House](https://lucide.dev/icons/house) SVG。反馈：本地线性图标。
- 记录列表：复用八月版项目 Demo 的置顶、项目和历史区域。

项目主导航使用 `项目-收起.svg`，项目列表展开与收起分别使用 `项目-打开.svg` 和 `项目-收起.svg`；与八月版项目 Demo 的实际引用一致。

缺少图标时，优先从 [Lucide](https://lucide.dev/) 选取，保存到当前 Demo 后使用。

- 功能页左上角 Copilot 入口：使用用户提供的 16×16 SVG，保存为 `Copilot.svg`。
- 交易入口：本地双向买卖箭头 SVG，颜色、线宽与主导航一致。
- 无限画布：采用 [Lucide Square Dashed Mouse Pointer](https://lucide.dev/icons/square-dashed-mouse-pointer)，保存为 `canvas.svg`；消息中心采用 [Lucide Bell](https://lucide.dev/icons/bell)。颜色与线宽适配现有侧栏，官方许可保存在 `LUCIDE-LICENSE.txt`。
